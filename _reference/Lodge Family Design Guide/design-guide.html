A trail by day, and the lodge at dusk

Everything a family app is made of, drawn with The Lodge’s real tokens. Switch between Day and Dusk at the top. Both are designed, and every surface here has both. The rules behind each part are in 01-ui-and-ux.md, and the data side is in 02-data-and-storage.md.

Color

Rare, and always meaning something. Components never contain a hex value: everything is a token.

Surfaces and text

Accents: one job each

Each accent pairs a soft background with its deep ink (5–7:1). Text on a filled accent uses on-accent: white by day, near-black at dusk, because Dusk’s accents are lighter.

How the data fits together

One SQLite file per app. Each module owns the tables named after it, and they meet only through the host.

A ref names anything, in any module

crm:9a1c2b3d4e5f40718293a4b5c6d7e8f9

The module that owns it, then a random 32-character id from db.new_id(). No autoincrement numbers, so two apps’ rows can share one database. core:me (proposed) means whoever owns the app.
